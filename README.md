# GitHub Issue Radar

A personal GitHub issue monitoring bot that helps me keep track of new issues created in selected GitHub repositories.

## Features

- Monitor selected GitHub profiles and repositories.
- Detect newly created issues.
- Send notifications through Telegram.
- Automatically check for issues on a schedule.
- Prevent duplicate notifications.

## Tech Stack

- Python
- GitHub REST API
- Telegram Bot API
- GitHub Actions
- JSON

## Project Status

🚧 Currently under development.

## Goal

Build a personal tool that helps me discover open-source contribution opportunities without manually checking GitHub every day.
